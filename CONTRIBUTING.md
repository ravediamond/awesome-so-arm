# Contributing

PRs welcome. Guidelines:

1. One link per bullet, with a one-line note on what it is and why it matters.
2. Prefer repos/docs with evidence of working (green CI, real-robot video, reproducible steps).
3. Star counts, if cited, are snapshots — note the date.
4. Keep the emerging sections honest: sparse is fine, padding is not.
5. No AI-generated attribution watermarks; plain, direct prose.
